# HowMuchAh

A planned mobile-first app for a private school badminton group to track attendance and shuttlecock contributions. Players will see group attendance and their own account; organisers will manage fees, guests, and payments.

**Status: Planning only. The app has not been implemented.**

See [PLAN.md](PLAN.md) for the agreed requirements, proposed technical approach, and implementation checks. Any examples use fictional Player A/B data; this repository contains no real player or payment data.
